# AdoptMe

A simple React app built as one of my first projects to practice CRUD functionality.

## Features
- Display a list of animals available for adoption
- Add a new animal
- Edit animal details
- Delete an animal
- Filter/search

##  Tech Stack
- React
- Basic CSS styling

## Starting App

Clone this repository

start backend
- cd server
- npm install
- node index.js

start frontend
- cd client
- npm install
- cd public
- npx serve .
